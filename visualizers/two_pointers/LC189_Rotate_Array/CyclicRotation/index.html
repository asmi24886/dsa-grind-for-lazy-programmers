📖 Algorithm: Cyclic Replacement

Concept: Start at index 0, pick up the value (ball), place it at (i+k)%n, pick up what was there, repeat.

Key: With n=7 and k=3, gcd(7,3)=1, so we need only 1 cycle.

Path: 0→3→6→2→5→1→4→0 (7 moves total, back to start)

Result: Each element moves exactly k=3 positions to the right (with wrap-around).
